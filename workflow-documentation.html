1 Authentication & Dual-Token Lifecycle

Dual-token strategy combining an ephemeral Access Token (15 mins) for request headers with a secure, rotated Refresh Token (7 days) in HttpOnly cookies:

1
User Enters Mobile Number POST /api/auth/login

Visitor or Owner enters their 10-digit mobile number. No passwords required. API checks PostgreSQL for an existing profile.

2
Account Verification & Token Issuance 200 OK or 404 Auto-Register

If registered, server issues short-lived Access Token (15 min) + sets HttpOnly Refresh Cookie (7 days). If new, user enters Name & Role to register.

3
Authenticated Request Execution Authorization: Bearer <token>

Protected routes (Create Listing, Upload Photos, View Owner Leads) authenticate the user via JWT header middleware.

4
Seamless Token Rotation POST /api/auth/refresh-token

When access token expires, client silently requests new token pair using HttpOnly cookie without interrupting user session.

2 Property Listing & Media Upload Workflow

Complete pipeline for creating listings across 6 categories and attaching high-resolution photo galleries:

1
Owner Fills Property Specifications POST /api/residential-rent

Selects category (Rent, Resale, PG, Commercial, Land). Form validates required fields (City, Locality, Rent/Price, BHK).

2
Database Normalization & UUID Generation Prisma ORM Insert

Record is saved to category table (e.g. ResidentialRentProperty) with isActive: true and unique UUIDv4.

3
Gallery Photo Upload (Up to 9 Photos) POST /api/residential-rent/:id/photos

Multer checks file type (JPEG/PNG/WebP) and enforces 5MB max size per image. Photos are linked to property UUID.

4
Live in Search Feed & Owner CRM 201 Created

Listing is immediately discoverable in public feed and managed under "My Properties" with View, Edit, Reorder, and Delete actions.

↓

5 Lead Capture & CRM Workflow

End-to-end lifecycle for connecting interested tenants/buyers directly to owners with automatic 24-hour lead deduplication:

1
Buyer Expresses Interest Click "WhatsApp Owner" or "Call Owner"

Buyer triggers lead ingestion on the property landing page while viewing listing details and photos.

2
24-Hour Deduplication & Anti-Spam Check POST /api/leads

Backend checks if the same user inquired on this property within the last 24 hours. If found, it updates the timestamp idempotently without duplicate alert spam.

3
Direct WhatsApp Bridge Launched https://wa.me/<owner_mobile>

Opens WhatsApp Web / Mobile app pre-populated with property title, locality, and price for 100% direct owner communication with zero broker fees.

4
Owner CRM Dashboard Record GET /api/leads/property/:propertyId

Owner sees verified buyer details (Name, Mobile, Timestamp) in their Owner Portal with customizable lead status (Interested, Contacted, Visited, Closed).
